# marklromano.github.io

The Romano Assets website moved to **https://romanoassets.github.io** (repo [romanoassets/romanoassets.github.io](https://github.com/romanoassets/romanoassets.github.io)).

This repo only forwards old links: `index.html` and `404.html` send every address, including deep links like `/prefab-builder/docs/`, to the same page on the new site. Version 0.8.0 of the Prefab Builder Kit has the old address built in, so keep this repo and its GitHub Pages site switched on.
